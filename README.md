# Agent · AI Agent 学习库

> 与 `ML` / `LLM` / `math-foundation` / `statistics-for-qs` 并列的一条 AI 学习线：把「AI Agent」当成一个独立主题，从概念、历史、原理、现状到应用，用一份可交互的单文件网页承载，后续持续迭代。

**在线看**：https://aayloo.github.io/Agent/

## 内容结构

- **序 · 一次任务的生命周期**：目标 → 拆解 → 调工具 → 观察 → 自检重试 → 交付与记忆。右侧舞台随滚动演示，图标自带微动效。
- **1 概念**：三个必要条件、与聊天机器人的分界、四层概念地图（构成／组织／工程／安全，含 skills、MCP、hooks、子智能体）、L0–L4 自主性阶梯、六组最容易混的概念。
- **2 历史**：Transformer → 少样本 → 推理与行动 → 工具调用 → 多模态与计算机操作 → 编码 Agent 与协议标准化 → 从演示到交付。含八个节点的可点时间轴与三条教训。
- **3 原理**：七步执行循环（可分步演示，每步标出最容易出错的地方）、六层构成、单智能体与多智能体、错误累积（十步各 95% → 约 60%）。
- **4 现状**：已经跑通的与仍然困难的、六个瓶颈、能不能上线的三条判断。
- **5 应用**：九个场景与成熟度、两条上手路径、接下来盯什么。
- **附录**：30 条术语速查，支持关键词过滤。

## 形态与技术

- 单文件、无外部依赖、离线可开：`index.html`
- 左文右图滚动叙事：右侧粘性舞台随滚动推进，小图标持续做微动作（眨眼、放大镜扫描、光标闪烁、数据下落、地球自转、闸门三色灯轮转、印章下压、对勾画出、记忆层叠入）
- 三套皮肤可切换：纸墨（默认）／蓝图／机台，选择会被记住
- 尊重 `prefers-reduced-motion`；`Ctrl/⌘ + P` 可直接导出 PDF

## 内容口径

- 只讲概念、事实与结构性判断，不放市场规模与预测数字
- 明确区分「已经发生的工程事实」与「前瞻性判断」
- 全文零表格，属于叙事型阅读材料，不是速查手册（速查部分在附录术语表）

## 更新方式

直接改 `index.html`，推送到 `main` 后 GitHub Pages 自动更新。
